# ForNIIAS

Задание №1 реализовано в проекте Task1-ParkFilling
Задание №2 реализовано в проекте Task2-ShortestWayFinding

Все задания и тесты выполняются на тестовой схеме станции, поставляемой
сущностью HardcodedRailwaySchemeProvider.
Для удобства восприятия был добавлен рисунок этой тестовой схемы станции - его можно найти
по пути ClassLibrary1\Images\RailwayScheme.png
На данном рисунке номера точек совпадают с именами точек в тестовых данных.
Номера секций - совпадают с именами секций в тестовых данных.
Цвета линий совпадают с именами парков в тестовых данных (серая линия - участок без парка).
На рисунке также подписаны координаты X,Y точек, которые совпадают с координатами 
пикселей, в которых они расположены (поэтому координата Y возрастает сверху вниз).
